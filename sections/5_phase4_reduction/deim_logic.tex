\subsection{Sub-Phase 4.3: Discrete Empirical Interpolation (DEIM) and Unassembled DEIM (U-DEIM)}
\label{subsec:deim_logic}

As an alternative to energy-based sampling, this sub-phase explored interpolative hyper-reduction using the \acrlong{deim} and its element-level extension, Unassembled DEIM (\acrshort{deim} variant). While ECSW acts directly on the virtual work integrals, DEIM approximates the non-linear internal force vector field $\mat{F}_{\text{int}}(\vect{u}_r)$ by projecting it onto a separate collateral basis $\mat{U}_F \in \mathbb{R}^{n \times m}$ extracted from nonlinear force snapshots:
\begin{equation}
    \mat{F}_{\text{int}}(\mat{V}_r \vect{u}_r) \approx \mat{U}_F \vect{c}(\vect{\mu})
\end{equation}

To determine the interpolation coefficients $\vect{c}(\vect{\mu})$ efficiently without evaluating the full vector, a greedy selection algorithm determines a specialized interpolation index vector $\vect{p} = [p_1, \dots, p_m]^T$ and corresponding projection matrix $\mat{P} = [\vect{e}_{p_1}, \dots, \vect{e}_{p_m}] \in \mathbb{R}^{n \times m}$ (where $\vect{e}_{p_k}$ is the $p_k$-th column of the identity matrix $\mat{I}_n$). The greedy index selection proceeds as:
\begin{enumerate}
        \item \textbf{First Index Selection}: Find the coordinate corresponding to the maximum absolute value of the first collateral basis mode $\vect{u}_1^F \in \mathbb{R}^n$:
        \begin{equation}
                p_1 = \arg\max_{i=1,\dots,n} |u_{i, 1}^F|
        \end{equation}
        Initialize the projection matrix $\mat{P}_1 = [\vect{e}_{p_1}] \in \mathbb{R}^{n \times 1}$ and basis matrix $\mat{U}_1 = [\vect{u}_1^F]$.
        \item \textbf{Iterative Greedy Expansion}: For each mode $j = 2, 3, \dots, m$:
        \begin{enumerate}
                \item Solve the interpolation system for the mode coefficient vector $\vect{a} \in \mathbb{R}^{j-1}$:
                \begin{equation}
                        \left( \mat{P}_{j-1}^T \mat{U}_{j-1} \right) \vect{a} = \mat{P}_{j-1}^T \vect{u}_j^F
                \end{equation}
                \item Evaluate the interpolation residual vector $\vect{r}_j \in \mathbb{R}^n$:
                \begin{equation}
                        \vect{r}_j = \vect{u}_j^F - \mat{U}_{j-1} \vect{a}
                \end{equation}
                \item Select the coordinate index that maximizes the remaining interpolation error:
                \begin{equation}
                        p_j = \arg\max_{i=1,\dots,n} |r_{i, j}|
                \end{equation}
                \item Update the projection matrix and basis matrix collections:
                \begin{equation}
                        \mat{P}_j = \begin{bmatrix} \mat{P}_{j-1} & \vect{e}_{p_j} \end{bmatrix}, \quad \mat{U}_j = \begin{bmatrix} \mat{U}_{j-1} & \vect{u}_j^F \end{bmatrix}
                \end{equation}
        \end{enumerate}
\end{enumerate}
The final interpolation projection matrix is defined as $\mat{P} = \mat{P}_m$. This allows the online projection to evaluate the exact nonlinear internal forces at the selected DEIM degrees of freedom only:
\begin{equation}
        \mat{P}^T \mat{F}_{\text{int}}(\mat{V}_r \vect{u}_r) = (\mat{P}^T \mat{U}_F) \vect{c}(\vect{\mu}) \implies \vect{c}(\vect{\mu}) = (\mat{P}^T \mat{U}_F)^{-1} \mat{F}_{\text{int}}\vert_{\mat{P}}(\vect{u}_r)
\end{equation}
where $\mat{F}_{\text{int}}\vert_{\mat{P}}(\vect{u}_r) = \mat{P}^T \mat{F}_{\text{int}}(\mat{V}_r \vect{u}_r)$ maps the localized forces at the $m$ active degrees of freedom.

\subsubsection{Unassembled DEIM (U-DEIM) Extension}
Standard DEIM still exhibits an offline-online bottleneck in finite element frameworks because evaluating even a single spatial row index within a global assembled vector requires looping over all physical mesh elements connected to that node. To completely achieve element-level lifting decoupling, \textbf{Unassembled DEIM (U-DEIM)} was deployed.

Instead of reducing the global assembled vector, U-DEIM constructs a snapshot matrix out of un-assembled, localized element internal force vectors $\vect{f}_e$. The interpolation is performed directly within the localized element vector space, meaning the online physics core only needs to evaluate isolated element routines matching the interpolation index map:
\begin{equation}
    \mat{F}_{\text{int}}(\mat{V}_r \vect{u}_r) \approx \sum_{e \in \widehat{\Omega}_U} \mat{L}_e \mat{U}_{f,e} (\mat{P}_e^T \mat{U}_{f,e})^{-1} \vect{f}_e\vert_{\mat{P}_e}(\vect{u}_r)
\end{equation}
where $\mat{L}_e$ handles standard global assembly mapping, and $\widehat{\Omega}_U$ represents the sharply restricted set of interpolated integration cells.

\subsection{Sub-Phase 4.4: Quantitative Evaluation and Hyper-Reduction Comparison}
\label{subsec:hyper_reduction_comparison}

To validate and compare the relative effectiveness of the three hyper-reduction strategies, a comparative study was conducted using the plate-with-a-hole benchmark under varying geometric and force parameters. The full-order model (FOM) is discretized using an exact bivariate NURBS mesh of $E = 3,200$ elements, corresponding to $n = 6,564$ high-fidelity degrees of freedom.

The reduced basis size is fixed at $r = 15$ modes, capturing $\theta = 99.999\%$ of the singular value energy spectrum. The numerical performance, accuracy, and computational efficiency metrics are summarized in Table~\ref{tab:hyper_reduction_metrics}.

The numerical results highlight the following critical structural behaviors:
\begin{itemize}
        \item \textbf{The Galerkin Projection Overhead}: Without hyper-reduction, the Galerkin ROM actually runs slower than the high-fidelity FOM solver ($0.92\times$ speedup). This represents the lifting bottleneck in action: evaluating and projecting the nonlinear tangent stiffness matrix over all $3,200$ elements creates severe computational overhead that wipes out any coordinate reduction advantages.
        
        \item \textbf{ECSW Energy Conservation}: ECSW exhibits the highest accuracy among all hyper-reduction strategies with a relative $L_2$ error of just $0.054\%$. Because ECSW directly minimizes the virtual work integration error rather than approximating the discretized force field rows, it preserves the physical strain energy balance of the continuum exactly.
        
        \item \textbf{U-DEIM Element-Level Autonomy}: Unassembled DEIM (U-DEIM) provides a significant performance advantage over standard DEIM ($34.6\times$ vs. $11.5\times$ speedup). By isolating interpolation to unassembled element force arrays, U-DEIM completely avoids the topological search loops and global matrix reconstruction indexing required by the standard global DEIM formulation.
\end{itemize}

\begin{devnote}
The code blocks testing DEIM and U-DEIM configurations allow us to compare error preservation directly against ECSW. While standard DEIM requires tedious mesh topology assembly parsing at runtime, the U-DEIM variant aligns perfectly with our native JavaScript array layout, processing localized chunk computations smoothly without triggering heavy index transformations.
\end{devnote}
