        \item[\textbf{Governing System}] $\mat{M}(\boldsymbol{\mu})\ddot{\vect{U}} + \mat{C}(\boldsymbol{\mu})\dot{\vect{U}} + \mat{K}(\boldsymbol{\mu})\vect{U} = \lambda(t)\mathbf{F}_{\text{ext}}$ with Rayleigh damping $\mat{C} = \alpha_M \mat{M} + \beta_K \mat{K}$.
        \item[\textbf{Implicit Integration}] Newmark-$\beta$ / Generalized-$\alpha$ time solver coupled with penalty Dirichlet boundary clamping ($k_p = 10^{30}$).

    \end{description}

Equipped with the reference pullback transformation derived in Chapter \ref{ch:pullback}, high-fidelity Full Order Model (FOM) simulations can now be evaluated consistently on $\hat{\Omega}$ to collect transient snapshot datasets and benchmark reduced order approximations. This chapter formulates the implicit dynamic time integration scheme, presents baseline stress and displacement field solutions, and demonstrates the severe computational bottleneck ($\approx 450\,\text{ms}$ per time step) that prevents real-time execution without model reduction.

% ------------------------------------------------------------------------------
\section{Governing Dynamic Equations \& Flowchart}
% ------------------------------------------------------------------------------

Here, we formulate the semi-discrete dynamic equilibrium equations and compare physical-domain remeshing against reference-mapped integration.

The high-fidelity transient response of the structural continuum is governed by the semi-discrete second-order system:

\begin{equation}
    \mat{M}(\boldsymbol{\mu}) \ddot{\vect{U}}(t) + \mat{C}(\boldsymbol{\mu}) \dot{\vect{U}}(t) + \mat{K}(\boldsymbol{\mu}) \vect{U}(t) = \lambda(t) \mathbf{F}_{\text{ext}}
\end{equation}

where $\mat{M}$ is the consistent mass matrix, $\mat{C} = \alpha_M \mat{M} + \beta_K \mat{K}$ is the Rayleigh damping matrix, and $\mat{K}$ is the stiffness matrix. Figure \ref{fig:remesh_vs_pullback} illustrates the computational flowchart comparing classical physical remeshing with reference domain assembly.

\section{Boundary Conditions \& Implicit Dynamics Solver}
% ------------------------------------------------------------------------------

Next, we detail the penalty method for boundary clamping and present the step-by-step Newmark-$\beta$ / Generalized-$\alpha$ implicit time integration algorithm.

Homogeneous Dirichlet clamping at $x=0$ is enforced via the \textbf{Penalty Method} by adding a large stiffness parameter $k_p = 10^{30}$ to diagonal entries of constrained boundary DOFs:
\begin{equation}
    \mat{K}_{\text{eff}}[i, i] \gets k_p, \quad \vect{F}_{\text{eff}}[i] \gets 0 \quad \text{for constrained boundary DOFs } i
\end{equation}
While selecting $k_p = 10^{30}$ increases the condition number of $\mat{K}_{\text{eff}}$, this is an accepted engineering trade-off that avoids complex master-slave DOF elimination while ensuring exact zero-displacement clamping.

Algorithm \ref{alg:fom_dynamics} summarizes the step-by-step implicit dynamics solver.

\begin{algorithm}[htbp]
    \caption{Full Order Model (FOM) Implicit Dynamics Solver}
    \label{alg:fom_dynamics}
    \begin{algorithmic}[1]
        \Procedure{StepDynamicsFOM}{$\vect{U}_n, \dot{\vect{U}}_n, \ddot{\vect{U}}_n, x_c, r, \sigma, \Delta t$}
        \State Assemble consistent mass $\mat{M}(x_c, r)$ and stiffness matrix $\mat{K}(x_c, r)$
        \State Compute Rayleigh damping: $\mat{C} \gets \alpha_M \mat{M} + \beta_K \mat{K}$
        \State Compute external load vector: $\vect{F}_{\text{ext}}^{n+1} \gets \text{calculateExternalForceVector}(t_{n+1})$
        \State Set Newmark constants: $a_0 = \frac{1}{\beta \Delta t^2}$, $a_1 = \frac{\gamma}{\beta \Delta t}$, $a_2 = \frac{1}{\beta \Delta t}$, $a_3 = \frac{1}{2\beta} - 1$, $a_4 = \frac{\gamma}{\beta} - 1$, $a_5 = \Delta t \left( \frac{\gamma}{2\beta} - 1 \right)$
        \State Formulate effective stiffness: $\mat{K}_{\text{eff}} \gets \mat{K} + a_0 \mat{M} + a_1 \mat{C}$
        \State Formulate effective force: $\vect{F}_{\text{eff}}^{n+1} \gets \vect{F}_{\text{ext}}^{n+1} + \mat{M}(a_0 \vect{U}_n + a_2 \dot{\vect{U}}_n + a_3 \ddot{\vect{U}}_n) + \mat{C}(a_1 \vect{U}_n + a_4 \dot{\vect{U}}_n + a_5 \ddot{\vect{U}}_n)$
        \State Apply penalty clamping at left edge ($x=0$): $\mat{K}_{\text{eff}}[i, i] \gets 10^{30}, \quad \vect{F}_{\text{eff}}^{n+1}[i] \gets 0$
        \State Solve linear system: $\vect{U}_{n+1} \gets \text{gaussianElimination}(\mat{K}_{\text{eff}}, \vect{F}_{\text{eff}}^{n+1})$
        \State Update kinematics: $\ddot{\vect{U}}_{n+1} \gets a_0 (\vect{U}_{n+1} - \vect{U}_n) - a_2 \dot{\vect{U}}_n - a_3 \ddot{\vect{U}}_n$
        \State Update velocity: $\dot{\vect{U}}_{n+1} \gets \dot{\vect{U}}_n + (1 - \gamma)\Delta t \ddot{\vect{U}}_n + \gamma \Delta t \ddot{\vect{U}}_{n+1}$
        \State \Return $\vect{U}_{n+1}, \dot{\vect{U}}_{n+1}, \ddot{\vect{U}}_{n+1}$
        \EndProcedure
    \end{algorithmic}
\end{algorithm}

\section{Computational Bottleneck \& Model Parameters}
% ------------------------------------------------------------------------------

The following analysis quantifies the online solve times and memory demands of the FOM, highlighting the exact computational bottleneck motivating model reduction.

High-fidelity Full Order Model (FOM) discretization scales and online computational demands are structured below (with comprehensive solver constants detailed in Appendix \ref{sec:appendix_sim_params}):

\begin{table}[htbp]
    \centering
    \caption{Full Order Model (FOM) discretization parameters and online solution complexity.}
    \label{tab:fom_parameters}
    \begin{tabular}{l p{9.0cm}}
        \toprule
        \textbf{FOM Parameter}            & \textbf{Quantitative Value / Characteristic}                                              \\
        \midrule
        \textbf{Bivariate Elements ($E$)} & $3,200$ elements                                                                          \\
        \textbf{Physical DOFs ($N$)}      & $6,564$ degrees of freedom                                                                \\
        \textbf{Time Step ($\Delta t$)}   & $0.01\,\text{seconds}$ ($1,000$ time steps for $T=10\,\text{s}$)                          \\
        \textbf{Online Matrix Solve Time} & $\approx 450\,\text{ms}$ per time step ($\approx 7.5\,\text{minutes}$ per simulation run) \\
        \textbf{Real-Time Feasibility}    & Unsuitable for interactive WebGL Digital Twins ($<1.5\,\text{ms}$ target)                 \\
        \bottomrule
    \end{tabular}
\end{table}

These quantitative demands (Table \ref{tab:fom_parameters}) underscore the online computational bottleneck of the full order model, demonstrating the necessity of projection-based reduced order modeling.

\section{Chapter Summary}
% ------------------------------------------------------------------------------

In conclusion, we summarize the FOM baseline results and set up the POD basis extraction and ECSW hyper-reduction presented in Chapter \ref{ch:rom}.

\begin{tcolorbox}[colback=lightbg, colframe=accentcyan, title=\textbf{Key Takeaway}, fonttitle=\bfseries]
    The Full Order Model provides accurate dynamic stress and displacement fields but requires $\approx 450\,\text{ms}$ per time step. In Chapter \ref{ch:rom}, we apply projection-based Reduced Order Modeling (POD) and Energy-Conserving Sampling and Weighting (ECSW) hyper-reduction to slash evaluation time to sub-millisecond rates ($<1.5\,\text{ms}$).
\end{tcolorbox}
